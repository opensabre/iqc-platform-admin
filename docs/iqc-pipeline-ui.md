# 流水线任务界面增量

## 2026-10-23 已发布Selector灰度任务

原灰度模式复用SelectorAssetLibrary，可选择显式会话或已发布Selector版本；内联Selector仅固定版本任务可选。command复制引用/名称/并发/请求键，创建不明后原请求重试，服务端返回原冻结任务/分配/选数。沿原权限与回执，不增加敏感正文和请求端点。当前构建检查，实际HTTP/组织角色/交互/worker仍待，后端契约见iqc-pipeline-rollout-tasks.md；周期事件灰度尚待集成。

## 2026-10-23 周期灰度目标

原周期编辑器增加显式当前灰度策略模式，序列化iqc-periodic-rollout-definition-v1/rollout引用；旧固定版本协议保留。灰度目标不伪造发布版本，切回固定模式需重新选择版本，原Selector/自动重试/计划预览及敏感读取/关闭清理复用。每实例首次冻结当前策略，后续扩量回退只影响新实例；当前构建检查，实际权限/页面/SQL/worker待独立验证。

## 业务统计中的灰度观测（2026-10-23）

原BusinessQualityReport组件/API类型增加可空rollout来源，按冻结修订/基线候选侧别显示原比例、状态、版本及公开Hash；数据分组和指标由原业务统计接口计算，前端不自行重算/合并。原显式任务/EID、组织范围、权限变化与迟到响应清理继续。任务分配比例与会话观测比例分开说明，同Dataset受控对照指向现有Benchmark。普通历史组无rollout时保持原展示。编译构建终态见协作记录，真实页面和权限生命周期专项待独立验证。

### 可选模型调用费用与耗时

业务统计增加“包含所选结果轮次的调用费用与耗时”，默认关闭且只对当前已有模型调用查看权限的用户展示；沿原report端点追加includeModelUsage=true。CostSummary类型共用，不以JS浮点数重算费用；金额/币种/已知未知计数和调用平均毫秒直接按服务端字符串展示。无匹配调用明确为未确认费用，另展示结果轮次绑定与耗时测量覆盖。撤权/重新授权均清报告与代次，结果费用区再检查当前grant；原默认API三参数调用保留，普通统计不受额外grant限制。真实页面与HTTP/SQL联合验证待B。
