原编辑器在冻结事实下仅展示上下文明示的模型声明，保留精确 valueJson 文本与原原因/来源节点/版本/运行序号；不将融合结果或人工纠正值冒充模型声明。每条可显式勾选，选择有来源支持/与来源矛盾/来源不足，引用该原观察证据或冻结会话消息并填原因；没有默认结论，未勾选不算已标注。
