# 流水线依赖图编辑

复用PipelineDependencyGraph、原节点列表和dependsOn/onError/fallbackNodeId，不创建图持久化模型或新API。独立分支feature/iqc-prd-dag-ui基于已提交提前满足设计器b4dc28d。

- 从节点右侧输出端口拖到目标左侧输入端口，按选定连接类型新增依赖或设置/替换备用路径；SVG屏幕坐标转换兼容滚动与缩放。捕获指针并处理取消，停用编辑时终止拖线。
- 同一操作可用源/目标/类型表单和键盘完成。点击或键盘选择现有边后可移除；备用移除显式恢复FAIL_PIPELINE，保留原重试次数，不悄悄改为CONTINUE。
- 原节点点击打开原配置，不创建平行属性模型。命令纯函数保留NodeDraft所有配置、映射、JSON草稿和版本引用，仅更新目标dependsOn或来源备用配置。
- 自依赖、未知/重复节点、逆向/循环依赖、重复边、停用依赖来源和非法备用路径拒绝；备用目标须停用、非递归且依赖可用。新错误不能使已配置备用路径失效。
- disabled同时在图控件、拖线回调与父组件命令处理防御，读取配置仍可用。删除依赖不自动重写变量输入映射或提前满足策略；原保存/发布校验仍权威，缺失引用必须显式修正。

节点仍按依赖深度自动布局，未新增布局持久化。拖拽节点库、完整画布/属性布局及浏览器/真实保存运行验收仍在完整PRD范围，不能以本批端口连线宣称全部可视化设计器完成。编译状态以根协作记录为准；Root未新增或执行测试，无SQL/部署。
