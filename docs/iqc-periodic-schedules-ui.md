# 周期调度管理

## 复用与缺口

复用现有 HTTP 客户端、权限 composable、Pipeline 发布目录和版本 API、SelectorAssetLibrary 发布版本选择及任务详情链接。现有任务页仅管理一次任务，不能维护 Cron 定义、不可变版本与周期实例，因此新增独立调度页面及薄 API 模块，不复制执行或选择器管理逻辑。

调度默认停用；保存、发布、启用分别操作。发布版本不可编辑。界面显示 UTC 计划游标、调度错误和任务原始状态/EID；更新权限仍由后端按固定创建者校验。构建仅证明源码可编译，运行验收另行进行。

## 界面约束

六字段 Cron、IANA 时区、含时区 ISO 有效期、错过计划策略、1–100 最大补跑与 1–32 任务并发。Pipeline 与 Selector 均选择已发布的精确版本；目录分页，不以加载到的首批目录代表全部资产。修改定义会清空旧预览，发布要求保存后草稿无修改并再次确认修订号。异步目录、版本和实例使用请求代次防止旧响应覆盖当前对象；保存/发布/启停/预览禁止重入。权限不足时隐藏对应读取与写入操作。

接口复用统一分页 `records/current/size/total`。任务跳转 `/tasks?taskId=...` 复用当前任务详情行为；UTC 游标按后端 UTC 字段原值展示。
