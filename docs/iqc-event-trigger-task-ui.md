# 事件接入任务展示

复用原任务列表、状态字典、详情与权限，不新建接收编辑器或页面。状态字典缺少新状态时由本地补齐筛选选项：WAITING_INPUT（等待输入）、TRIGGER_EXPIRED（触发已过期）、TRIGGER_CONFLICT（触发内容冲突）。等待输入期间继续原列表轮询，可取消，不能执行或恢复；过期/冲突可按既有终态删除。

列表与详情仅显示来源、事件 ID、等待/错误原因及最早重试 UTC；详情可显示输入/请求指纹。任务 API 类型仅增加这些可选字段，不声明或展示 triggerRequestJson，不打印提交正文或后台授权。原结果展示与 EID 保持原行为。源码构建不代表运行接收与权限验收。
