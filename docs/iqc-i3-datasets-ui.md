# I3 金标与数据集前端

当前实现对应后端 `docs/iqc-evaluation-datasets.md`；仅金标和数据集资产管理，不宣称评测指标、发布门禁已实现。

- `api/evaluation.ts`：金标 5 类、数据集 8 类 API，扩展既有 QualitySample 类型，候选查询复用 `api/quality.ts` 的 listSamples。
- `GoldSampleEditor.vue`：sampleId 驱动加载、强类型事实/状态/值表单、冻结消息证据选择、难度标签、对象业务上下文、可选分数/标签/风险。标注使用 expectedRevision（首次 0），不提交用户身份。独立审核由服务器核实身份，未保存不能审核。审核历史分页、精确版本快照。expose hasUnsavedChanges()（含未提交审核原因）与 isBusy() 供上层关闭确认与请求保护，changed 供刷新。
- `evaluation-datasets/index.vue`：目录分页、草稿详情/创建更新、可用性、候选既有样本与分页批准版本选择、精确成员引用、冻结、版本历史与完整快照。按钮按各 API 权限显示。

不同样本/数据集与历史请求使用请求序号阻止旧响应覆盖新状态。JSON 编辑仅用于 OBJECT 值、业务上下文和高级标签期望；快照 JSON 只读文本插值。首次标注前没有冻结消息证据选择，保存后补充再审核。候选接口当前返回现有样本列表；审核历史总数包含退回版本，界面仅允许选批准版本。

根开发者已接入路由/菜单/样本库抽屉。最终 `npm run build` 的 vue-tsc 与 Vite 成功，仍有既有大包提示。依赖复用既有临时发布目录，没有安装或修改锁文件；未新增或运行测试，未运行数据库、浏览器或角色验收。标签高级 JSON 的稳定码对齐与评测准入仍属于后端待完成范围。

构建前审阅修正：候选列表与版本请求分别维护 loading 并合并，切换草稿清零候选与历史状态；金标首次加载不产生假脏状态，成功审核清原因。JSON 冻结输入用 shallowRef，事实编辑值限定标量，OBJECT 使用独立文本缓冲，避免 Vue 递归 UnwrapRef 深度实例化；核心事实协议仍保留强类型。
