# 归档事件订阅管理

复用周期资产的修订、发布确认及分页模式，现有 HTTP/权限/发布 Pipeline 目录 API、SelectorAssetLibrary 和任务详情跳转。周期页的 Cron 游标不适用于归档完成事件，因此新增薄订阅 API 与独立路由，不复制选择器或执行器能力。

订阅按归档记录时间 UTC 匹配 ConversationCompleted/ASRCompleted，有效期、输入等待秒数和任务并发由定义保存；选择器是可选的已发布版本引用。新建/发布后停用，需要显式启用；停用只阻止以后接收，不取消已接收任务。页面说明后台通过数据库归档发现事件，不宣称外部 MQ 接入。

订阅页面通过既有周期调度页的权限控制链接进入，复用组织菜单。有效期规范到整秒后重验；发布新版本会再次接收其时间范围内会话。最终 vue-tsc + Vite 构建通过（3408 modules），仅既有 chunk 大小警告。没有运行测试、浏览器或部署。
