## 当前运行证据

后端基线 `14396b2`（IQC 后端 #75），前端基线 `b7bd7a0`（前端 #76）及本 PR 的结果视图修复。
Playwright 使用真实 `views/tasks/index.vue`、`views/results/index.vue`、向导和结果组件，
请求经本地转发访问实际 Spring/H2 后端；没有拦截并伪造业务 API 响应。
挂载页使用本地路由及测试身份，未包含正式应用壳、OIDC 或组织服务验收。
规则、标签和会话为隔离数据，两个配置目录使用空测试表，不访问生产数据库。

联合任务 `2118867993715904514`，执行 `2118868302152437761`：

1. 从实际任务页打开四步向导，选择“退款会话.txt”。
2. 添加两个质检正则引擎及一个打标正则引擎，将第二个质检引擎上移。
3. 校验 POST 参数和详情冻结配置：退款初检 → 退款复核；打标引擎独立保留。
4. 配置两个质检引擎映射到同一目标，扣分制 100 分、扣 10 分；打标命中映射为 false。
5. 从任务列表点击“执行”，轮询完成后点击“查看结果”。实际评分 90.00，未重复扣分；标签 false 保留；三个引擎记录顺序正确。
6. 导航至实际结果中心，打开同一任务会话的结果明细，核对评分、标签及“退款”原文证据。

## 需求与证据边界

| 需求 | 当前证据 | 仍需补充 |
|---|---|---|
| 四步名称、提交和任务详情衔接 | 实际任务页浏览器创建成功 | 正式应用壳导航 |
| 批量选择 | 本轮实际任务页 | 无新的取数缺口 |
| 随机抽样、条件筛选在执行时取数 | 2026-11-06 真实组件/后端验收：创建名单为空，执行后有结果 | 本轮页面未重复动态模式 |
| 模拟列表与不足数量 | 前轮真实浏览器：请求 100、匹配及抽中 1；同列列表 | 大数据量性能不在当前证据范围 |
| 质检和打标独立或联合 | 联合任务本轮通过；单质检前轮通过；组件校验覆盖操作选择 | 单打标完整页面运行 |
| 各操作独立多引擎、排序和冻结配置 | 本轮提交数组、详情和执行记录一致 | DLS/LLM 的页面运行组合 |
| 失败留痕且继续、重试复用成功结果 | 后端 JointLabelMaterializationTransactionTest 联合执行/重试 HTTP 用例 | 浏览器异常组合与历史切换 |
| 原始输入、输出、证据保存 | 后端结果集测试；本轮页面原文证据和配置入口 | 不以截图代替全部持久化断言 |
| 汇总评分、标签且不隐藏冲突 | 本轮同目标双引擎只扣一次、false 保留；组件及处理器测试覆盖冲突 | 冲突完整页面验收 |
| 每个 LLM 的提示词、温度、超时 | 前后端参数及路由测试，配置冻结 | 实际模型 HTTP 请求参数证据 |
| 无新增知识库、风险中心、事实语义功能 | 本轮仅任务/结果模块；默认任务结果视图移除风险筛选和列 | 不宣称已删除 main 的历史功能 |

完成剩余项后再作整体结论，不以组件挂载、单测或构建成功替代正式应用链路验收。
