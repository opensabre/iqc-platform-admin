# 四步任务创建

任务中心点击“创建任务”进入独立页面 `/tasks/create`，复用现有四步向导，不再弹出对话框。路由使用 `iqc:task:create` 权限；侧栏仍归属任务中心。页头“返回任务列表”、取消和创建成功均返回 `/tasks`，重新加载任务列表。提交中禁用返回和取消按钮，避免重复提交。

1. 数据筛选：复用 `TaskDataSelector`；批量选择明确名单，随机/条件保存选数参数。
2. 规则与标签：配置 REGEX / DLS / LLM 的执行顺序、全部或部分标签以及 LLM Agent。
3. 触发计划：立即、定时或周期，使用北京时间。
4. 任务确认：名称、并发、数据范围、标签、引擎顺序和触发计划。

提交使用既有统一任务 API，发送 `dataSelection`、`configuration`、`trigger` 和 `concurrencyLimit`；预览种子不作为正式取数参数。评分、结果冲突及正式标签动作保持待定，不在此页面添加策略。

创建页独立加载已发布 Agent 和标签；任一目录失败时保留另一目录，可通过“重试加载”重取。任务列表不加载这些创建目录。表单错误保留已填写内容；网络无法确认提交结果时阻止再次提交，提示返回列表核对。
