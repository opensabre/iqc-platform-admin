# 向导任务结果查看

任务页现有“查看结果”按钮对新向导任务显示三个页签：质检评分、打标标签、引擎记录。质检和打标按任务启用状态显示；引擎记录始终可查看。沿用批次摘要、任务详情、执行历史和 result-hierarchy API，不新增页面或路由。后端依赖 iqc-platform PR #69（摘要）及 #70（原始结果详情）。

用户可选择实际执行数据中的会话，默认查询最新可用结果，也可选择特定执行。显示实际来源执行。只有结果处理器 FINAL 分数可显示为最终分；冲突/错误/未知保留原状态，纯打标不计分，false/0 不当作未知。候选通过 sourceEngineResultId 与 evidenceIds 关联证据。原始输出、错误原因、输入原文和本次参数均可展开查看。切换会话时使旧请求失效，防止覆盖新选择。

未取数、未执行、引擎已执行但处理未完成、请求错误各有独立提示。新任务不调用旧标签结果和洞察接口。旧任务抽屉保持原有逻辑。


结果中心的默认会话视图按“任务结果”组织，展示评分、目标计数和结果明细，
不显示风险筛选或高风险列，也不向会话结果接口发送风险筛选条件。
“本次结果明细”支持质检、打标或联合任务，展示相同的冻结结果集。
历史消息观察视图保留原有兼容展示，切换视图时清除风险筛选，避免隐藏条件影响任务结果。

页面级隔离验收范围和剩余项见 [原型验收记录](prototype-acceptance.md)。
