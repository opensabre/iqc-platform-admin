# 任务数据筛选

以 `docs/main-redesign/prototype.html` 为流程参考。复用 ConversationPicker 展示会话表格，TaskDataSelector 提供三种模式及参数表单。

- 批量选择：选择已处理好的会话，跨页保留名单，不因勾选重置页码。
- 随机抽样：保存筛选范围和数量；正式执行时抽样。预览返回一份样本，翻页和切回样本不重抽，可以切换全部匹配数据并查看本次抽中状态。
- 条件筛选：保存条件；正式执行时取数。模拟执行分页展示当前匹配列表。
- 随机及条件筛选数量不足时有多少处理多少；预览不冻结正式名单。
- 改条件清除旧预览，同时丢弃旧请求响应。加载失败清除旧数据并允许重试。

预览调用后端 PR #59 的 `POST /api/iqc/conversations/selection-preview`，会话数据范围由现有后端能力检查。批量列表继续使用已有会话查询接口。时间筛选使用会话开始时间，支持文件名、坐席、客户、渠道和业务编号。

当前交付范围：可复用筛选组件、真实预览 API 调用、原型规则校正及组件测试。**尚未接入任务页的创建向导。**现有旧创建接口的 SAMPLE 在创建时固定名单，不符合新需求；不能把预览名单转为 BATCH 后提交来伪装执行时抽样。新向导接入需要新的任务配置及执行时取数链路完成后单独交付。

验收：批量跨页不回跳、随机翻页不重抽、全量与样本切换不混淆、过时请求不恢复旧列表、数量不足提示、失败清除旧结果；运行 Vitest、TypeScript 检查与 Vite 构建。不把模拟原型或组件测试等同于任务执行验收。
